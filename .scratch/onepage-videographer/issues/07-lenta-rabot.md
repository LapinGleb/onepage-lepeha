# Лента работ с Vimeo-лайтбоксом

Type: task
Status: resolved
Blocked by: 02, 04

## Question

Реализовать ленту работ:

- массив объектов (`title`, `vimeo`, `poster`) в `js/main.js` — источник контента для ручной правки;
- рендер сетки 3/2/1 колонки из массива;
- постеры-заглушки, lazy-load;
- клик по карточке → лайтбокс с Vimeo-плеером (реализация по ресёрчу из тикета «Ресёрч: Vimeo-лайтбокс, OG-превью и lazy-load без библиотек»);
- доступность: фокус-ловушка, закрытие по Esc и фону, aria, возврат фокуса.

Критерий готовности: 6 заглушечных работ кликаются в лайтбокс на десктопе и мобе. Ответ — как менять работу (одна строка массива).

## Answer

Лента и лайтбокс собраны.

- **Лента** рендерится из массива `WORKS` в `js/main.js`; одна строка = одна карточка. Поля: `title`, `meta`, `vimeo`, `poster` + необязательные `hash` (unlisted) и `ratio` (`horizontal`/`vertical`). `vimeo` принимает и id (`"76979871"`), и ссылку (`"https://vimeo.com/76979871"`).
- **Как менять работу** — отредактировать одну строку в `WORKS`: пустой `vimeo` → неактивная карточка; пустой `poster` → градиентная заглушка (`ph-1…6`); путь в `poster` → `<img loading="lazy" decoding="async" width="800" height="1000">`.
- **Лайтбокс**: один `<dialog id="lightbox">` в `index.html`; iframe создаётся по клику и удаляется при закрытии (останавливает звук). URL плеера: `autoplay=1&muted=1&title=0&byline=0&portrait=0&dnt=1&playsinline=1` (+`h` для unlisted); соотношение задаёт `data-ratio`.
- **Доступность**: нативный `<dialog>` — фокус-ловушка и закрытие по Esc; клик по фону/крестику закрывает; фокус возвращается на карточку; `aria-label` на кнопке и диалоге, `title` на iframe.
- **Стили**: карточка-кнопка, иконка play, `.lightbox*` — в `css/styles.css`.
- **Заглушки**: все 6 работ ведут на демонстрационный ролик Vimeo `76979871`, постеры — градиенты. Реальные ссылки/обложки — тикет «Заменить заглушки реальным контентом».

Проверено: `node --check js/main.js` — OK; DOM-прогон логики на стабе — 6 карточек, корректный URL игрока, `h`/vertical, очистка iframe, возврат фокуса. В живом браузере (десктоп/моб) не открывал — нужна визуальная проверка.
