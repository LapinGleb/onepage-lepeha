## Question

Поднять верность обсуждения дизайна до конкретики. Сделать дешёвый, но конкретный артефакт (вызвать Skill tool с "prototype"):

- **style tile**: палитра тёмного кинематографичного направления (фон, текст, приглушённый акцент), 2 шрифта (заголовочный + текстовый), типографическая шкала, отступы/сетка;
- **грубый макет** всей страницы: Hero, Лента работ (3 колонки, карточка с постером и подписью), «О себе», «Контакты», футер;
- состояния: hover карточки, лайтбокс (схематично), мобильная версия (1 колонка).

Ограничения из карты: тёмное, современное, без копирования референса один-в-один; zero-build. Артефакт — статичный HTML и/или скриншоты, ссылку приложить к тикету. Это HITL-тикет: концепцию показывает и обсуждает человек, агент не отвечает за него.

## Answer

Артефакт: `prototype/index.html` (вызван Skill tool «prototype», ветка UI — «как это должно выглядеть»).

Три **радикально разных** направления, переключаются `?variant=A|B|C` или стрелками ‹ › / ← → в плавающей панели снизу. У каждого — свой style tile (палитра + 2 шрифта + шкала) и полный макет страницы (Hero → Работы → О себе → Контакты → футер), состояния hover карточки и схематичный лайтбокс (`<dialog>`), мобильная версия 1 колонка.

- **A «Кино» · редакционный** — крупная тонкая антиква (Cormorant Garamond + Inter), тёплый янтарный акцент `#C9A227`, первый кадр на 2 колонки, контакты крупными строками.
- **B «Мозаика» · плотный** — тяжёлый гротеск (Archivo Black + Inter), холодный стальной акцент `#8FA9C9`, мозаика кадров в hero, плотная сетка 3/2/1 с подписями поверх, контакты-пилюли.
- **C «Кадр» · сплит-скрин** — геометрический Syne + Inter, оранжевый акцент `#FF5A1F`, hero 50/50 (типографика / кадр), работы — горизонтальная «плёнка» со scroll-snap и таймкодами.

Прототип намеренно throwaway: реальных фото нет (кадры — градиентные заглушки), тексты/контакты фиктивные, персистентности нет. Рекомендация к согласованию (тикет «Согласовать дизайн с другом»): выбрать A/B/C или собрать гибрид («hero из B, лента из C»).
