# Map: сайт-визитка видеографа (one-pager)

Label: `wayfinder:map`
Tracker: local markdown (`.scratch/onepage-videographer/`)

## Destination

Готовый статический одностраничник видеографа, залитый на GitLab Pages, с дизайном, согласованным другом. Лента из 6 работ (Vimeo-лайтбокс) + короткое «О себе» + контакты; контент редактируется руками через массив в JS. До появления реальных материалов сайт живёт на заглушках.

## Notes

- **Domain**: русскоязычный сайт-визитка видеографа (свадьбы и события). Аудитория — регион заказчика. Только RU. Референс (не копировать): https://dreamtime.video/wedding/gryaznov.html
- **Execution is in scope** — эта карта ведёт не только к решениям, но и к собранному и задеплоенному сайту (override «plan, don't do»).
- **Зафиксировано при чартинге**:
  - zero-build статика: `index.html` + `css/styles.css` + `js/main.js`, без npm и сборки.
  - Секции сверху вниз: Hero → Лента работ → О себе → Контакты → футер.
  - Тёмное кинематографичное направление (чёрный фон, крупные кадры, тонкая типографика).
  - Лента: сетка 3/2/1 колонки, 6 работ, постеры → Vimeo-лайтбокс.
  - Контент работ — массив объектов (`title`, `vimeo`, `poster`) в `js/main.js`.
  - Контакты: Telegram, телефон, VK, e-mail — ссылками, без формы.
  - Musts: адаптив, lazy-load постеров, мета + OG-картинка, лёгкие CSS-анимации появления. Без cookie-баннера и аналитики (пока).
- **Skills для сессий**: `prototype` (дизайн), `grilling` + `domain-modeling` (согласование), `research` (техника/деплой). Тикеты называть по имени, не по номеру.
