# onepage-lepeha

Статический одностраничник видеографа: лента работ, «О себе», контакты. Без сборки — чистые HTML/CSS/JS. Клик по карточке открывает видео (VK или Vimeo) в лайтбоксе поверх страницы.

## Запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере, но пути к `css/` и `js/` относительные — удобнее поднять локальный сервер:

```sh
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Структура

```
index.html            разметка страницы: hero, работы, «О себе», контакты, лайтбокс
css/styles.css        стили (тема, сетка, лайтбокс, адаптив)
js/main.js            массив WORKS и вся логика: рендер ленты, лайтбокс, анимации
prototype/index.html  ранний прототип, на сайт не публикуется
.github/workflows/    деплой на GitHub Pages
```

## Правка контента

Почти весь контент живёт в двух файлах.

**Работы** — массив `WORKS` в `js/main.js:22`. Одна строка = одна карточка:

```js
{ title: "Аня и Дмитрий", meta: "Свадьба · 2024", source: "vimeo", video: "76979871", hash: "", ratio: "horizontal", poster: "" }
```

- `source` — `"vimeo"` (по умолчанию) или `"vk"`;
- `video` — id или ссылка на ролик; пусто — карточка неактивна;
- `poster` — путь к обложке; пусто — градиентная заглушка;
- `hash` — приватный ключ для unlisted-видео (необязательно);
- `ratio` — `"horizontal"` (16:9) или `"vertical"` (9:16).

**Контакты и заглушки** — `index.html`. В комментарии в `<head>` (`index.html:7`) перечислено всё, что нужно заменить: телефон, e-mail, портрет автора, логотип, канонический URL, `og:image` и постеры.

## Деплой

Пуш в `main` запускает `.github/workflows/pages.yml`: файлы `index.html`, `css/`, `js/`, `img/` собираются в `_site` и публикуются на GitHub Pages. `prototype/` и `.scratch/` в артефакт не попадают.

Разовая настройка репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Без этого шага `configure-pages` падает с `Get Pages site failed: Not Found`.

## Документация

- `CONTEXT.md` — словарь домена (работа, источник видео, лайтбокс); ADR'ы складываются в `docs/adr/`.
- `docs/agents/` — правила для агентов: трекер задач, ярлыки триажа, доменные доки.
- `.scratch/` — трекер задач (локальные markdown-файлы).
